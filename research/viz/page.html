Bytes moving through the caches: Goose compiling Goose

TL;DR

    The ladder over time

    Source to program, per rung, for each run of research/demo --ladder (median of its runs; whiskers are min and max). W1: front end + C compiler (stock fast: front end, TinyCC and the run, in one process). W2: wall time of the fixture suite, 8 jobs. A hollow mark is a rung whose outputs did not all check.

    Before and after: the self-hosted front end

    Each strip is one data structure of the self-hosted compiler (every Goose table is on a data stack of its own), drawn as the bytes it used; time runs left to right on one scale for both, so a shorter picture is a faster compile. Every pixel is a group of accesses, colored by the cache level that served them in the simulation, brighter where there are more. Before, the checker scanned the whole symbol table for each name: a green wedge growing with the table. After, a (scope, name) hash looks in one bucket.

    The C compiler is where the seconds are

    gcc's cc1 at -O2 compiling the C each front end wrote for W1 (cc1 is stripped, so its time is one stage; its memory is its machine stack, the heap where GCC keeps trees and RTL, and its image).

    Bytes moved per stage

    Bytes brought into L1 from each level (64 bytes per line filled), per stage. One scale for all front ends. Bold numbers on the left are L1 hits, which move nothing.

    Where the self-hosted compiler's bytes go, before and after

    Every access of the whole compile by data structure (exact counts, not sampled), on the same input.

    How this was measured

    Hardware counters (perf, Zen 4 ls_dmnd_fills_from_sys.*, 5 interleaved runs) give real totals and seconds; a Valgrind tool, research/viz/trace/bytemove.c, replays every load and store through a model of this CPU's caches (L1 32 KB 8-way, L2 1 MB 8-way, L3 32 MB 16-way victim cache, 64-byte lines, LRU, no prefetcher) and records which level served it. It matches cachegrind's L1 misses to 0.03% and the counters to within the prefetchers' share. Evidence: research/viz/METHOD.md. Regenerate everything: research/viz/regen.sh.
